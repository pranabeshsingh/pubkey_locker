Public key registry

Store, validate, and resolve SSH public keys.

A curl-friendly keyserver for signed key bundles. Upload a bundle, validate it, and resolve it by handle.

Upload key Lookup handle

$ curl https://pubkey.locker/alice.keys

$ curl https://pubkey.locker/alice.json

$ curl -X POST https://pubkey.locker/api/keys

Upload key bundle

Paste a signed JSON bundle. It is validated before storage.

Expected shape

{
  "version": 1,
  "handle": "alice",
  "keys": [{
    "type": "ssh-ed25519",
    "publicKey": "ssh-ed25519 ...",
    "fingerprint": "SHA256:..."
  }],
  "proof": {
    "message": "register alice",
    "signature": "base64...",
    "signedBy": "ssh-ed25519 ..."
  }
}
