Bundle JSON Payload

Specification Cheatsheet

Every bundle requires schema validation and a valid ownership proof signature before persistence.

  • version: Must be integer 1
  • handle: 1–64 characters (alphanumeric, _, -)
  • keys: Non-empty array of public key objects
  • type: ssh-ed25519, rsa-sha2-512, rsa-sha2-256, or ecdsa-sha2-nistp256
  • proof: Ownership challenge signature and signing key
Expected JSON Shape 
{
  "version": 1,
  "handle": "alice",
  "keys": [{
    "type": "ssh-ed25519",
    "publicKey": "ssh-ed25519 ...",
    "fingerprint": "SHA256:..."
  }],
  "proof": {
    "message": "register alice",
    "signature": "base64...",
    "signedBy": "ssh-ed25519 ..."
  }
}
